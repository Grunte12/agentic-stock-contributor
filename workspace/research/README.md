# research/ (stages 1-3)

One Markdown file per market question, named `<TOPIC>_<YYYYMMDD>.md` (for example `XMAS_NY_DEMAND_20261013.md`).

Each file holds:
- the buyer, placement and message per candidate (stage 1),
- the sub-niches with a buyer sentence each (stage 2),
- the `stock_report` tables pasted unchanged, with the scan date, and the season state from `lead_window` (stage 3),
- the decision: which sub-niches go to a brief, and why.

Check it with `stock_verify_doc` before you plan a batch on it: every number must come from a pasted table or carry `[m:<metric_id>]`.
Numbers you did not measure are `unmeasured`. Community tips go in with their date and source; they are not Adobe rules.

Knowledge topics: `mindset`, `niche-research`, `analytics-tools`, `community-evidence`.
